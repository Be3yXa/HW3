# 1. Алгоритм и блок-схема
1. Начало
2. Объявить константы:
  * kilocalories - количество килокалорий после перевода.
  * kilowatt_hours - количество кВатт/ч после перевода.
  * MJ_TO_KCAL - количество килокалорий в одном МДЖ.
  * MJ_TO_KWH - количество кВатт/ч в одном МДЖ.
3. Задать исходные данные:
  * megajoules - исходное количество мегаджоулей для перевода.
4. Вычислить количество килокалорий в заданном количестве МДЖ:
  * kilocalories = megajoules * MJ_TO_KCAL
5. Вычислить количество кВатт/ч в заданном количестве МДЖ:
  * kilowatt_hours = megajoules * MJ_TO_KWH
6. Вывести результаты расчетов с подстановкой всех значений в текст.
7. Конец
